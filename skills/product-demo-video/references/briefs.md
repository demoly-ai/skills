# Product demo brief examples

All products below are fictional.

## Feature walkthrough

Product: Pinboard Studio, a feedback board for product teams. Direction: `feature_walkthrough`.

```text
Show how a product manager turns customer feedback into a roadmap item. Start on the Feedback inbox, open a request, merge it with a duplicate, then press "Add to roadmap" and finish on the Roadmap view with the new card. Skip settings and billing.
```

Why it works: one task with a clear start and end screen, steps named the way the product names them, and pages to avoid.

## Onboarding flow

Product: Shiftly, staff scheduling. Direction: `onboarding_flow`. Needs a sign-in.

```text
For new restaurant managers. Start from the empty dashboard, add two employees, create next week's schedule with the drag-and-drop calendar, and end on the published schedule.
```

Sign-in: the user signs in to a test workspace in the live browser on the site. If the flow creates data, note that Demoly blocks write requests by default, so the account should already hold the sample employees and the brief should show using them rather than creating them.

## Weak, and how to fix it

```text
Demo our whole platform. Here is our admin login: admin@... / ...
```

Problems: "the whole platform" gives no flow to record, and the password must never go through chat. Ask which single task matters most, tell the user not to share the password, and point them to the live sign-in on the site.
